# CTrack-MoneyTracker
Website-based application using Python, calculating income and expenses as well as transaction records

## Usage

1. Go to New Terminal then type:
```bash
pip install flask
```
after that, wait a second then type like this:
```bash
python app.py
```
the ```app.py``` is depends on ur file name, if ur file name is ```money.py``` then type ```python money.py``` according to ur file :)
